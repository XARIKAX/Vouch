Verify an attestation yourself.

Every settled task carries an ed25519-signed receipt. Paste one below — the signature is checked in your browser against Vouch's public key. You don't have to trust us; you can prove it.

The public key lives at /v1/attestation/key. The signed message is the canonical JSON of the payload — the same offline check any third party can run. Get a real one from GET /v1/tasks/{id}/attestation.
